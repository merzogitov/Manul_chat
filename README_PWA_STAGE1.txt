МАНУЛ ЧАТ — PWA STAGE 1
=======================

Добавлено:
- manifest.webmanifest;
- service-worker.js;
- иконки 180x180, 192x192 и 512x512;
- standalone-режим;
- регистрация Service Worker;
- кеширование только статических файлов.

На этом этапе PUSH ещё не добавлен.
Сначала проверяем установку как приложения.

iPhone / iPad:
1. Открыть Манул Чат по HTTPS именно в Safari.
2. Нажать "Поделиться".
3. Выбрать "На экран Домой".
4. Запустить созданную иконку "Манул Чат".

Android:
1. Открыть сайт по HTTPS в Chrome.
2. Меню браузера.
3. "Установить приложение" / "Добавить на главный экран".

Synology / Docker:
- папку data НЕ удалять;
- перед обновлением желательно сделать резервную копию data;
- заменить файлы программы;
- пересобрать проект в Container Manager.

Проверочные URL:
    /manifest.webmanifest
    /service-worker.js

Следующий этап после успешной установки:
    Web Push уведомления о новых сообщениях.
