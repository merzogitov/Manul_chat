# Changelog

## 1.0 — 2026-08-09

Первый стабильный релиз **Манул Чат**.

### Интерфейс

- отображаемая версия изменена с `v8` на `v1.0`;
- исправлена ширина пузырей сообщений на ПК;
- исправлена прокрутка длинной переписки:
  - верхняя панель остаётся на экране;
  - список пользователей остаётся на экране;
  - заголовок диалога остаётся на экране;
  - поле ввода остаётся на экране;
  - прокручивается область сообщений;
- на мобильном Push-кнопка явно показывает:
  - `🔔 Вкл`;
  - `🔕 Выкл`.

### PWA

- установка на Android;
- установка на iPhone/iPad;
- manifest;
- service worker;
- PWA-иконки;
- корректный запуск через `/`;
- перенаправление неавторизованного пользователя на `/login`.

### Push

- Web Push для текста и изображений;
- автоматическое создание VAPID-ключа;
- хранение Push-подписок в SQLite;
- удаление недействительных подписок;
- отсутствие дублирующего уведомления при открытом активном чате.

### Docker

- `static/` вынесен в отдельный bind mount;
- HTML/CSS/JS теперь можно менять без Build/Rebuild;
- внешний порт изменён на:

```text
0.0.0.0:18080:8000
```

- удалены `.bat` и `.sh` файлы из релиза.

### Основные функции

- приватные диалоги 1-на-1;
- WebSocket;
- SQLite;
- online/offline;
- изображения;
- ответы на сообщения;
- очистка истории только для текущего пользователя;
- административная панель;
- защищённые вложения;
- production-режим;
- Secure cookie;
- SQLite WAL;
- Docker / Synology.
