# Changelog

## 2026.08.09 — UI + Push Status 1

Текущая версия:

```text
2026.08.09-ui-push-status1
```

### Исправлено

- на Android/PWA кнопка Push теперь явно показывает состояние:
  - `🔔 Вкл`;
  - `🔕 Выкл`;
- текст состояния больше не скрывается на мобильной версии;
- на ПК страница чата больше не прокручивается целиком;
- верхняя панель остаётся на экране;
- список чатов остаётся в своей колонке и прокручивается отдельно при необходимости;
- заголовок открытого диалога остаётся на экране;
- поле ввода сообщения всегда остаётся внизу;
- прокручивается только область переписки.
