МАНУЛ ЧАТ — PWA + PUSH 1
===========================

Версия:
    2026.08.09-pwa-push1

Исправлено:
- на ПК сообщения с пробелами больше не сжимаются до ширины самого
  длинного слова;
- пузырь держит фразу в одну строку, пока она реально помещается;
- длинные сообщения по-прежнему нормально переносятся.

Добавлено:
- Web Push;
- кнопка "🔔 Уведомления" в верхней панели;
- VAPID-ключ создаётся автоматически при первом запуске;
- закрытый/свёрнутый PWA получает системное уведомление;
- если чат сейчас открыт и виден, уведомление не дублирует WebSocket;
- push работает и для текста, и для изображения;
- при выходе push-подписка текущего сеанса удаляется;
- недействительные push-подписки (404/410) удаляются автоматически.

ВАЖНО:
Файл:
    data/vapid_private.pem
создаётся автоматически и должен сохраняться вместе с data/.
Не удаляйте его при обновлениях, иначе уже оформленные push-подписки
придётся создавать заново.

Можно задать контакт VAPID:
    VAPID_SUBJECT=mailto:you@example.com

Android:
1. Обновить и пересобрать контейнер.
2. Открыть установленный Манул Чат.
3. Нажать "🔔 Уведомления".
4. Разрешить уведомления Android/Chrome.
5. Закрыть или свернуть Манул Чат.
6. Отправить сообщение с другого пользователя.

iPhone/iPad:
Web Push работает для web app, добавленного на Home Screen.
Кнопку включения уведомлений нажимать уже внутри установленного приложения.

Если Android ранее запретил уведомления:
Настройки Android -> Приложения -> Манул Чат/Chrome -> Уведомления.
