# 🐱 Манул Чат

Приватный веб-мессенджер на Python / FastAPI.

## Возможности

- приватные диалоги 1-на-1;
- WebSocket для сообщений в реальном времени;
- статусы online/offline;
- история сообщений в SQLite;
- изображения JPG / PNG / WebP / GIF до 20 МБ;
- ответы на сообщения;
- очистка переписки только для текущего пользователя;
- административная панель;
- PWA: установка на Android и iPhone/iPad;
- Web Push уведомления о новых сообщениях;
- запуск в Docker / Synology Container Manager;
- production-режим с HTTPS и Secure cookie.

## Docker / Synology

Сборка рассчитана на запуск через Docker.

Папки `data/` и `static/` подключаются в контейнер как bind mounts:

```yaml
volumes:
  - ./data:/app/data
  - ./static:/app/static
```

`data/` содержит постоянные данные приложения.

`static/` содержит HTML/CSS/JS/иконки и подключён отдельно специально для быстрой разработки интерфейса.

В ней находятся:

```text
data/messenger.db
data/uploads/
data/vapid_private.pem
```

`data/` нельзя удалять при обновлении приложения.

`vapid_private.pem` создаётся автоматически при первом запуске версии с Push.
Если его удалить, существующие Push-подписки перестанут работать и пользователям
придётся включать уведомления заново.

## Обновление

1. Сделайте резервную копию `data/`.
2. Замените файлы приложения новой версией.
3. Не заменяйте и не удаляйте существующую папку `data/`.
4. Выполните именно **Build / Rebuild** Docker-образа.
5. Запустите контейнер.

Для текущей сборки в журнале должно быть:

```text
Манул Чат: 2026.08.09-static-bindmount1
```

При сборке Docker должна появиться строка:

```text
Push dependencies: OK
```

Если этой строки нет, используется старый Dockerfile или старый build context.

## HTTPS

В production приложение должно работать через HTTPS:

```text
Интернет
   ↓
HTTPS :443
   ↓
Reverse Proxy
   ↓
HTTP
   ↓
manul-chat:8000
```

Порт контейнера напрямую в Интернет публиковать не рекомендуется.

## Установка как приложение

### Android

Откройте Манул Чат по HTTPS в Chrome:

```text
⋮ → Установить приложение
```

После установки появится отдельная иконка `Манул Чат`.

### iPhone / iPad

Откройте Манул Чат по HTTPS в Safari:

```text
Поделиться → На экран Домой
```

После этого запускайте чат с созданной иконки.

## Push-уведомления

В чате нажмите:

```text
🔔 Уведомления
```

и разрешите системные уведомления.

После успешного включения кнопка показывает:

```text
🔔 Уведомления: вкл
```

Push используется, когда приложение закрыто или находится в фоне.
Когда окно чата открыто и видно пользователю, сообщение приходит через WebSocket
без дополнительного системного уведомления.

Поддерживаются уведомления о:

- текстовых сообщениях;
- изображениях.

При выходе из аккаунта Push-подписка текущего сеанса удаляется.

## Проверка PWA

Эти адреса должны открываться по HTTPS:

```text
/manifest.webmanifest
/service-worker.js
```

Manifest запускает приложение с:

```text
start_url = "/"
```

Поэтому при отсутствии действующей авторизации пользователь попадает на страницу входа.

## Локальный запуск без Docker

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Запустить:

```bash
python app.py
```

Для разработки используется `APP_ENV=development`.
В production используется `APP_ENV=production` и HTTPS.

## Быстрое изменение интерфейса

После перехода на отдельный bind mount `static/` Docker **не нужно пересобирать** при изменении файлов:

```text
static/chat.html
static/login.html
static/admin.html
static/style.css
static/service-worker.js
static/image/*
```

Достаточно сохранить изменённый файл на Synology и обновить страницу.

Для HTML/CSS обычно достаточно обычного обновления страницы или `Ctrl+F5`.

После изменения `service-worker.js` может потребоваться закрыть и снова открыть PWA либо обновить страницу несколько раз, чтобы браузер активировал новую версию Service Worker.

Build / Rebuild всё ещё нужен при изменении:

```text
app.py
requirements.txt
Dockerfile
compose.yaml
```

Изменение `compose.yaml`, добавляющее `./static:/app/static`, требует **одной пересборки/пересоздания контейнера**. После этого HTML/CSS/JS можно править без пересборки.
